# Formation Docker

Formation pratique pour apprendre Docker en conteneurisant une petite application composée d'un frontend (React) et d'un backend (FastAPI).

## Déroulé

1. [01-premier-conteneur](exercices/01-premier-conteneur/README.md) - bases de Docker : images, conteneurs, cycle de vie.
2. [02-frontend-et-backend](exercices/02-frontend-et-backend/README.md) - construire et lancer séparément les images du frontend et du backend.
3. [03-docker-compose](exercices/03-docker-compose/README.md) - faire tourner les deux conteneurs ensemble avec Docker Compose.
